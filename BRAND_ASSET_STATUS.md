# SuaveForge Brand Asset Status

This package contains the exact final-logo geometry extracted from the public SuaveForge motion SVG.

## Included variants

- `assets/suaveforge-logo-dark.svg`: black mark for light surfaces
- `assets/suaveforge-logo-light.svg`: warm-white mark for dark surfaces
- `assets/suaveforge-logo-brand.svg`: blue transparent app/favicon derivative

The shape is not redrawn or approximated. The only differences are surface-appropriate color and raster size. The original motion SVG and extraction report are included in the Windows project under `assets/brand-source/`.
