# 다운로드 기록 연결 방법

1. Google 스프레드시트를 새로 만듭니다.
2. `확장 프로그램 → Apps Script`를 엽니다.
3. 기본 코드를 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. `배포 → 새 배포 → 웹 앱`을 선택합니다.
5. 실행 계정은 본인, 액세스 권한은 링크를 받은 사용자에게 허용합니다.
6. 생성된 웹 앱 URL을 `assets/config.js`의 `trackingEndpoint`에 붙여넣습니다.
7. `trackingEnabled`를 `true`로 바꿉니다.

기록 항목: 다운로드 시각, 이름/회사명, 연락처, 동일 대상 누적 횟수, 릴리스, 버튼 위치, 페이지 URL, 유입 경로, 브라우저 정보.

> GitHub Pages 자체만으로는 방문자의 이름을 알 수 없습니다. 반드시 사용자가 입력한 이름/회사명을 기록하는 방식으로 운영해야 합니다.
